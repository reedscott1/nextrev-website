    Takeout Order

    Takeout is entered one of two ways:

    • A new takeout order — the whole order is takeout, usually entered by the host. Change the order's Order Type to Take Out Order.
    • Takeout added to a dine-in order — a server adds takeout food to an order that has already been served. The order stays dine-in; add the Take Out item after the takeout food.

    New takeout order

    When an order is takeout from the start, remember to change the Order Type to Take Out Order. Steps vary by device.

    On Station

    1. Open Clover Dining
    2. Tap the Bar Tab
    3. Tap the plus button (bottom right) to open a new order
    4. Under Order Type on the left, select Take Out Order
    5. Enter the guest count and tap Save
    6. Proceed with taking the order — go to Updating Orders → Add Items

    On Flex

    1. Open Clover Dining
    2. Tap the Bar Tab
    3. Tap the green plus button (bottom right)
    4. Tap the green Pay button (top left)
    5. From the dropdown in the top left, select Take Out Order
    6. Tap the back button to return to the menu → take the order

    Note

    The order prints to the kitchen with Take Out at the top of the ticket.

    Add takeout to a dine-in order

    Use this when a server has already served a dine-in order and the customer wants food to take out.

    1. Open the order back up
    2. Add the takeout food item
    3. Add the Take Out item directly after it

    Key difference

    The order stays Dine-in. The Take Out item is a signal to the kitchen: it prints on the ticket right after the food item added before it, marking that item as takeout.
